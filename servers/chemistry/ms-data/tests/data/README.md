# Test data

`dda_test.d/` is a tiny synthetic Bruker timsTOF DDA dataset (`analysis.tdf` + `analysis.tdf_bin`,
4 frames, 3 precursors) generated by Sander Willems for the timsrust project and distributed in
the `timsrust_pyo3` 0.4.1 source package (https://github.com/jspaezp/timsrust_pyo3,
`tests/data/dda_test.d`) under the Apache-2.0 licence. It is used unchanged.
